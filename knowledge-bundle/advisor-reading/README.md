## 读完如何进入个人知识库

在右侧选择用途和顾问，指出当前资料及问题；要求区分原文、研究转述和自己的判断。需要留存结论时保存到自己的笔记，填写日期、出处与适用条件。书房中的公共材料只读，个人记录写入个人集合；公开来源不是额外本机读写或执行命令的授权。
