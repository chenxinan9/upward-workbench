# macOS 桌面入口与升级

桌面双击“睿顾台.app”，在独立窗口打开同一份本机知识工作区。程序与私人数据分开保存，关闭窗口不等于停止后台服务。

需要 macOS、Python 3.11+、Xcode Command Line Tools。浏览器模式不需要 Xcode。

## 首次安装

在本版本源码目录执行：

```sh
python3 desktop/install.py --data-dir "$HOME/UpwardData"
```

安装器会编译窗口和图标，将白名单中的完整程序部署到当前用户的 `Library/Application Support/向上成长顾问/程序`，初始化自己的可写笔记集合，并保留随包 51 份顾问。不会把顾问写到全局 Skill 目录，不会自动扫描或复制其他私人资料。

默认桌面入口是 `睿顾台.app`，可用 `--destination` 指定新位置。已有 App 或运行副本不会被静默覆盖。

## 升级

1. 退出睿顾台窗口，并停止本机后台服务；仅关闭窗口不足以完成停止。
2. 备份私人数据目录。外部 Vault 默认不包含在数据目录备份中，需要单独备份或显式选择集合。
3. 从新版本源码执行：

```sh
python3 desktop/install.py --data-dir "$HOME/UpwardData" --upgrade
```

升级必须沿用原数据目录。从原向上工作台升级时，默认新入口是「睿顾台.app」；安装器核对旧 App 的同一 Bundle ID，成功后把旧入口移入回滚备份，不复制私人数据。`Library/Application Support/向上成长顾问` 和内部标识继续保留以保证兼容。新程序先在临时目录检查，再整体替换旧运行副本，防止已移除模块残留。旧程序和桌面配置保留在私人应用支持目录的“安装备份”中；笔记、对话和用户设置保留。运行部署失败会尝试恢复旧程序与设置，并保留失败候选供核查。

不要把旧程序的文件逐个复制回新版，也不要用别人的 `desktop.json`、认证或模型验证回执覆盖自己的配置。需要回滚时，停止服务并按相应安装备份恢复完整程序和桌面配置，然后核对数据目录。

## 如何核对

打开桌面入口后应看到左侧知识目录、中间内容和右侧 Codex。打开自己的笔记，确认内容与 Obsidian 的同一文件一致；查看顾问团目录是否存在。模型验证独立进行，安装成功不等于已经登录或成功调用模型。

部署回执保存在私人 `deployment.json`，包括实际运行文件哈希。修改开发源文件不会自动更新这个运行副本。

程序保留既有 Bundle ID 与应用支持目录，以兼容历史入口。安装不修改系统隐私权限、开机启动或定时任务。外部来源在默认浏览器打开，工作台只加载固定的本机地址。
