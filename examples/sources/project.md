# 合成练习项目草案

此文件全部为虚构教学数据。记录日期：2025-01-02。以下是方案建议，不是本人已经采用的任务，也不是任何成果记录。

摄影方向：先用已有设备选择一个室内静物，尝试改变光线方向；比较照片时只讨论一个变量，记录选择原因。阶段结果可以是一份带说明的练习选片集。是否拍摄、拍多少、何时完成，由使用者取舍。

英语方向：给一张自己有权使用的照片写简短说明，接受反馈后重写，并解释修改原因。阶段结果可以是一份保留初稿、反馈和重写的对照笔记。没有测试分数或学习效果预测。

这两个练习可以相互连接，但不要求同时开启。若当前没有照片，可以先整理一个问题或观察，不把素材数量当成能力进度。
