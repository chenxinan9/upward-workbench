# 向上工作台

**51 份顾问 Skill、配套方法与案例、人生指南正文，加上你的成长工作台和本地知识库。**

遇到一个问题，找合适的顾问方法一起想；有了想法，直接对话，把它留下来，再变成目标、行动和阶段复盘。向上将人生方向、日常实践与知识积累放在同一处：左侧找内容，中间阅读整理，右侧始终有 Codex **AI 助理**。

顾问团覆盖创业、产品、学习、哲学、创作、职场、健身与个人财务等议题，包括纳瓦尔、巴菲特、乔布斯、费曼等人物方法视角，也有一人公司、预算、睡眠、沟通等功能顾问。[查看 51 份顾问清单 →](docs/advisors.md)

## 一条命令，先体验

macOS / Linux，需要 **Python 3.11+**：

```sh
curl -fsSL https://raw.githubusercontent.com/chenxinan9/upward-workbench/main/install.sh | bash
```

安装器下载固定版本、校验 SHA-256，建立独立的合成演示并打开浏览器。示例是虚构的摄影与英语练习，**不会复制原作者或你电脑里的私人资料**，也不会自动登录 AI、调用模型或安装全局技能。已有目录不会被覆盖。可先[查看安装脚本](install.sh)；其他启动方式见[上手说明](docs/getting-started.md)。

## 顾问团怎么陪你做事

- **理清方向：**“人生全景”看长期愿望，“目标与计划”看阶段结果，“我的今天”看已安排的行动。
- **把话留下来：**直接说“保存这个想法”“采用刚才的目标”或“复盘最近 30 天”，保存后在对应页面回看。
- **知道回答依据：**显示实际读取的资料、选用的顾问及理由，以及工具进度、文件写入回执。
- **把知识留在自己手里：**Markdown 保存在本地；Obsidian 可打开同一文件夹，双方编辑会检查文件冲突。

保留浅蓝书房界面；顾问书房在知识库上方。右侧将设置收进菜单，把主要空间留给回复。附件、语音、模型与发送集中在输入区。

“本机助手”可联网、执行命令、读取系统允许访问的文件，默认仅工作目录可写，越界操作按请求审批。“资料顾问”围绕所选资料工作。备忘录和 MCP 连接器需要本机已配置并授权；不会自动拥有 Codex 桌面的全部插件。[能力与权限说明 →](docs/codex-native-capabilities.md)

## 接上自己的 Codex

先在本机安装并登录 Codex CLI，再从右侧“对话设置”中的“模型与连接设置”检查连接。选择器只列出实际验证成功的模型；检查会发起真实模型请求，使用所选账号及路由的额度。向上沿用本机认证，不随包提供账号或密钥，也不会接管 Codex 桌面的原聊天。

每轮可选择用途、顾问与资料范围：**我的资料与顾问 / 当前文档 / 顾问与公开资料**。公开进度与摘要可见，隐藏推理全文不在展示范围内。[连接与使用步骤 →](docs/getting-started.md)

## 下载后就有的资料

- **51 份顾问 Skill 与配套参考资料**：方法详解、案例、练习和适用边界，随包安装，无需原作者的私人资料。
- **《高性价比人生指南》34 个章节、122 篇补充与核实文档**：按 CC BY 4.0 保留署名、来源和版本。
- **22 份来源导读**：包含纳瓦尔、巴菲特、历史经典、学习与健康等。导读与链接不冒充已收录的原著全文。

打开左侧“高性价比人生指南”或“顾问来源导读”，可以直接阅读、搜索；在右侧让 Codex 读取正文、选择顾问、给出依据。无需先把整套资料安装到全局 Skill 目录。[资料内容、出处与用法 →](docs/knowledge-library.md)

## 公开的是什么

**55 条顾问来源目录、51 份可分发 Skill 及配套参考资料、33 项登记方法**，三种口径分别统计。4 条来源因许可条件未分发正文；人物顾问是方法视角，不是本人、授权代言或完整著作。每份缩编保留出处与许可，[查看许可审查](docs/advisor-bundle-audit.md)。

公开内容是程序、顾问方法与案例、许可明确的公共知识正文、通用流程与合成示例。个人档案、健康财务、真实目标、聊天、模型回执和宣传创作资料不在包内。
