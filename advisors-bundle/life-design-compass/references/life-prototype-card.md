# 生活原型卡

这张卡用于探索“哪种生活更适合当前处境”，不预测五年后的收入或身份。方法源自本技能列明的开源上游文字；以下表格和案例为本项目原创适配，不是机构原版工作纸。

## 从方向到试验

先保留原问题，再列：已经知道的事实、解释或担心、现实限制、可改变的部分。不同路径应在工作方式、时间分配、责任、环境或价值交换上有差异，不能只换三个职位名。对照健康、责任、兴趣和关系时不要求平均用力。

选一个原型时只留下必要信息：

| 项目 | 需要明确的内容 |
| --- | --- |
| 待验证问题 | 哪个未知会改变选择？ |
| 最小试验 | 访谈、短体验，或小作品；不先做重大承诺 |
| 成本与底线 | 时间和资金上限，不愿牺牲什么 |
| 第一步与日期 | 谁做什么、何时开始；未定就写待安排 |
| 观察 | 怎样的真实反馈能支持或削弱假设 |
| 回看与分岔 | 何时复盘；继续、缩小、换方案的条件 |

## 合成演练

虚构用户同时考虑自由接案、团队工作、分享知识。他目前保留本职收入，每周只有三个小时可探索，不愿借钱。

不能直接判断“你适合创业”。先比较三种生活结构：自己获取并服务客户、在团队中集中做擅长的部分、以兼职分享验证教学兴趣。收入想象不是证据。

若用户倾向分享，可用一次小范围试讲验证“我是否喜欢准备、解释与处理提问的日常”，而不只验证“我喜欢被认可”。限制为三小时、零额外预算，收集听众理解情况和自己的精力感受；日期由用户安排。没有正面反馈也要记录原因，不能用一次试讲否定整条路径。

## 常见误判

- 明明在找方向，却急着分解一个尚未选择的目标。
- 因用户感到兴奋，就把建议写成已采纳计划。
- 将家庭、身体或制度限制视为努力不足。
- 用五年时间线制造精确承诺，忽略未知和选择权。
- 所有原型都以收入和点赞衡量，漏掉生活本身的质量。

需要执行既定目标时转回现有行动拆分或 WOOP 方法；需要回顾已发生的阶段变化时用阶段反思。保存、提醒和知识共享均由宿主工具权限决定。
