# 责任边界与合作地图

适用：比较焦虑、讨好或关系责任混乱时。

## 区分责任，不割断关系

“课题分离”在现代阿德勒相关诠释中常被使用，本页不把它冒充阿德勒逐字提出的口诀。判断边界时同时看决定权、结果承担者、已有承诺和权力差异；不能只问“这是谁的事”就退出合作。

| 问题 | 记录方式 |
|---|---|
| 谁能决定？ | 写具体事项的决定权，不按人格贴标签 |
| 谁受影响？ | 列直接影响及应沟通的人 |
| 我承诺了什么？ | 区分明确约定、默认期待和单方面猜测 |
| 我愿意提供什么？ | 给可持续帮助及上限，保留对方拒绝权 |
| 哪些需要共同商议？ | 时间、资源、分工不是任何一方单独拥有的课题 |

## 比较转成参与

“我比别人差”先拆成具体差异：技能、资源、结果、经验还是受到的评价。能练的部分设计练习，资源不足寻求支持；不要推断自卑一定是逃避借口，也不要从出生顺序断定人格。

合成例：小组成员担心自己的汇报不如同伴。可将目标改为准确解释自己负责的实验和未知项，并提出一次互相提问的演练。贡献不等于牺牲自己，也不依赖所有人夸奖。

## 鼓励语句检查

描述一个可观察行动及其帮助，例如“你把不确定数据单列出来，别人更容易核对”，而非“你终于证明自己优秀”。避免有条件的尊重。每次边界调整后回看：自己的责任有没有履行、对方选择是否得到尊重、共同事务有没有被遗漏。

这里是合作反思工具，不是人格诊断。面对胁迫、伤害或持续严重困扰，优先安全和合适支持。
