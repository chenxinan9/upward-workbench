# 处境、资源与真实选择空间

适用：角色期待、经济依赖或关系限制影响选择时。

## “可以选”与“选得起”分开

一项选择在形式上开放，不代表每个人都有相同条件。记录可动用的收入、时间、技能、照护责任、身体状况、社会支持和现实风险。只收集影响当前问题的部分，不预设用户性别、家庭角色或应当追求的生活模式。

## 处境地图

| 层次 | 需要辨认 |
|---|---|
| 自己重视什么 | 本人表达的愿望与外界赞许分开 |
| 外界安排 | 谁制定规则，谁得到机会，谁承担成本 |
| 实际资源 | 哪些条件已有，哪些需要争取或积累 |
| 相互依赖 | 关系中是否能协商、拒绝、保留独立支持 |
| 可扩展选择 | 改变哪个条件会真实增加下一步可能性 |

合成例：一个照护者希望继续学习，却没有整块时间。只说“勇敢做自己”没有解决安排。更具体的方案可能是协商照护分工、选择可中断学习方式、争取支持并保留休息。照护劳动有价值，不应被贬为低等生活；本人也不应因此失去其他发展机会。

## 关系与自主

检查双方是否被当作有独立目的的人，而非支持另一方理想的附属。经济安排、隐私、社交和时间是否允许协商？不能仅用“你自己选择的”掩盖胁迫或资源匮乏。

交付当前限制、仍有的空间、可争取支持与一个可承受的步骤。尊重选择不意味着替用户决定离开或留下。《第二性》与《模糊性的伦理学》可以帮助思考处境与自由；本页为当代应用，不照搬时代中的全部观点，也不复制现代译文。
