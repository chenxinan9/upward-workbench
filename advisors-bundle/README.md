# 可独立使用的顾问技能缩编包

本包实际包含 **51 份自包含 SKILL.md**：33 个人物视角、18 个功能顾问。每份具有不同的输入、方法、可检查输出和适用边界；无需另下研究笔记即可在对话中使用。这里不是55份原版镜像，也不包含名人本人或机构授权。

`manifest.json` 是工作台阅读入口，`methods.json` 登记33个跨顾问去重的方法子集。33不代表上游所有著作或全部技能的方法总数；同一方法可对应多个顾问。`excluded.json` 保留4个未分发条目及原因。

## 安装与使用

工作台可直接按manifest读取各目录SKILL.md，不必先把51份写进全局技能目录。需要在支持文件夹技能的Codex环境使用时，可先选择少量顾问。

从本目录执行以下命令。`$HOME` 只引用使用者现有目录，不改变环境配置：

```sh
python3 install.py --destination "$HOME/.codex/skills" --name think-woop
python3 install.py --destination "$HOME/.codex/skills" --name think-woop --apply
```

第一条只预览，不写文件；第二条执行复制。省略`--name`会选择全部51份。安装器验证文件哈希，拒绝覆盖已有同名目录；遇到已有技能请比较版本，或用另一个空目录试装。安装后让宿主刷新技能发现或开启新对话；文件复制完成与宿主已加载是两件事。可用 `$think-woop` 等名称调用，是否自动选择取决于宿主。

也可将单个技能目录连同LICENSE、provenance.json一起复制到自己的技能目录。不要只分享SKILL正文而丢掉归属和许可。
