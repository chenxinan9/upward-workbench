# 长期生活、习惯与处境判断

适用：需要把短期行动放回长期生活中判断时。

## 判断行动在服务什么生活

把活动、近期结果与长期追求分开。读书、工作或锻炼是活动，成绩和收入是结果；更长远的生活还涉及关系、能力、健康与参与。不要仅以当天愉快或单项产出判断一个选择是否值得长期坚持。

## 中道不是平均值

从实际处境判断某种回应是否恰当：对谁、在什么时候、针对什么、以何种方式及到什么程度。过度与不足有助于比较，但并非所有行为都存在合理“中间量”，不为欺骗或伤害寻找折中额度。

| 判断层 | 需要写清 |
|---|---|
| 目的 | 这项行动最终服务哪种生活价值？ |
| 处境 | 能力、资源、责任和受影响者是谁？ |
| 手段 | 有哪些可行选择，各有什么代价？ |
| 品格与关系 | 反复这样做会形成怎样的习惯和信任？ |
| 反馈 | 哪个事实会让判断改变？ |

合成例：面对同伴的错误，完全沉默可能妨碍协作，当众羞辱也会破坏信任。较恰当的动作可能是私下指出可核对的问题并约定修复；若涉及安全风险，则必须及时升级。这里没有一条适用所有情境的“温和”答案。

## 小型习惯试验

选择一项具体实践，记录是否逐渐更容易作出符合目标的判断，而不只计次数。回顾也包括外部条件：时间、健康、资源确实影响可行性，不把困难全当作德性不足。原典《尼各马可伦理学》可按幸福、习惯、中道与实践智慧串联阅读；历史等级和排斥观点不作为今天的规范。
