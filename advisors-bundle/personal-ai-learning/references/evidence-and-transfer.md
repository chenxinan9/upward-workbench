# AI学习的证据、练习与迁移

适用：想制定学习计划或检验自己是否真学会时。

## 从交付倒推学习范围

先写一个可观察任务：能解释、比较、制作、排错或作出什么判断。再选择必要概念，避免让AI列一份巨大课程表。资料、模型解释和自己的理解分开保存：模型讲得顺并不能作为事实证据。

## 一次练习的证据链

| 环节 | 保留什么 | 通过条件 |
|---|---|---|
| 输入 | 已有权使用的材料、出处、版本或日期 | 知道论点来自哪里 |
| 初次输出 | 不看答案的解释、操作或作品 | 看得到当前理解，而非粘贴AI答案 |
| 反馈 | 具体错误、正确依据、仍未知之处 | 能指出哪一处为什么需要改 |
| 重试 | 学习者自己的改写或重新操作 | 已修正问题，不只表示听懂 |
| 迁移 | 换背景或限制后的同类任务 | 能说明哪些条件改变、方法如何调整 |

## 可直接使用的请求

“先让我回答，再针对我漏掉的条件给提示。不要立刻给完整答案。”“把这个结论对应到我提供材料的段落；没有来源的地方标待核实。”“换一个背景出题，保留同一核心原理，最后让我解释理由。”

合成例：学习区分平均数和中位数。先解释一组虚构等待时间，再加入一个极端值，预测两种指标会怎样变化，计算后核对预测。最后讨论在哪个业务问题里使用哪一个更合适。完成计算不等于已经理解指标选择。

## 周期复盘

记录最常出现的误解、需要查证的事实、已能独立完成的任务及仍需提示的部分。下一轮优先修一个反复卡点，复用已有材料，不以生成笔记页数或对话长度衡量学习。只在用户需要时保存到其现有记录位置；本技能不自动写入全局记忆或替人购买课程。
