# 保障、免责与续保条款阅读表

适用：手上有实际保单，需要理解能保什么及条件时。

## 资料必须对应同一份合同

确认保险产品、版本、保险期间、批单及特别约定。营销页、同名旧条款和别人保单不能代替用户合同。缺少实际条款时只能说明术语和需要哪些页，不判断个案是否赔付。

## 逐项对照

| 条目 | 需要保留的原文信息 | 通俗解释应说明 |
|---|---|---|
| 保障事件 | 定义、触发条件与证明材料 | 何种情况进入保障判断 |
| 金额 | 保额、比例、次数、年度/单次限额 | 哪个上限作用在哪个范围 |
| 费用扣减 | 免赔、其他赔付、目录或项目限制 | 剩余费用不一定全部可赔 |
| 免责与义务 | 等待期、告知、职业/地域及通知条款 | 与保障同样显著呈现 |
| 续保 | 期间、条件、费率、期满安排 | 保证续保不是永久无条件 |
| 退出与中止 | 犹豫期、现金价值、欠费、复效 | 依实际合同而非通用天数 |

## 合成核对例

宣传写“住院保障”，实际条款可能还有费用范围、免赔和上限。正确输出应逐项列出条件及页码，不能只依据标题给出“能赔”。没有明确计算顺序时，列为需向保险公司书面核对的问题，不自行补一个看似合理的公式。

## 结论格式

每项用“条款位置—原文要点—我的解释—本人事实是否已知—待确认问题”。对于歧义，保留原句并展示不同解释可能影响什么；不要把AI摘要说成保险人确认。法律效力、时限与争议处理需结合当前地区规则和专业支持。

资料可以在本地整理，账户和身份信息不需要上传公共检索。不会因看见不足就默认建议退保，也不自动购买新产品或代办索赔。
