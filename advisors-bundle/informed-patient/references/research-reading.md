# 医学资料阅读与不确定性记录

适用：用户带来论文、报道或检查术语希望理解时。

## 先界定资料回答了什么

从题目、摘要和实际方法核对研究人群、干预或暴露、比较条件、观察结局与时间。新闻标题、作者推测、研究结果和针对个人的建议分开，不从相关性直接推出因果。

## 阅读检查表

| 检查项 | 为什么会影响理解 |
|---|---|
| 人群与场景 | 与本人不同，适用性可能有限 |
| 研究设计 | 随机试验、观察或个案支持的推断不同 |
| 结果口径 | 相对变化、绝对变化及基线风险不是一回事 |
| 不确定性 | 样本、区间、偏倚和失访影响可信程度 |
| 利弊 | 有益结局之外还要看不良结果和代价 |
| 证据位置 | 原文哪个表、段落支持这个结论 |

合成算例：一个虚构研究里某事件由每100人2例降到1例，相对下降50%，绝对差为每100人1例。两个表达都可能成立，但不能让人误以为有50人受益；也不能把该结果直接预测到本人。此数例不对应真实治疗研究。

## 报告结论

写“研究发现……；在……人群/条件下；没有回答……；对当前问题仍需核对……”。若未打开原文，只能说明可见摘要范围，不编引用、样本量或结论。历史论文也应结合当前适用指南及更新证据，不把一篇研究当最终答案。

本页用于理解资料和准备与医生讨论的问题，不生成个体治疗处方。检索使用通用医学词，去除身份和完整健康记录；无法核实时明确保留未知。
