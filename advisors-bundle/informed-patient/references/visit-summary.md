# 一页就诊摘要与问题清单

适用：需要把症状和检查整理给临床人员时。

## 让信息能被核对

优先记录最影响生活的问题、开始时间、变化、频率、伴随情况，以及做过的处理和反应。标明信息类型：本人回忆、设备测量、检验报告、医生记录或尚未证实的推测。不要将过期测量自动视为当前情况。

| 区块 | 内容 |
|---|---|
| 本次诉求 | 最希望医生帮助澄清的一个问题 |
| 时间线 | 出现、加重、缓解与就诊等关键时点 |
| 已有资料 | 原检查名称、日期、单位、参考范围及缺页情况 |
| 相关背景 | 与本问题有关的用药、过敏及既往信息 |
| 尚不清楚 | 缺失资料和需要核对的假设 |
| 优先提问 | 检查目的、可能利弊、替代方案、后续观察条件 |

## 问题如何写得有用

“这个结果说明了什么、又不能说明什么？”“下一步检查会改变哪项决定？”“哪些变化需要提前联系医生？”“已有安排如果效果不好，如何回看？”不强行凑疾病清单，也不把正常参考区间或单次异常直接解释成确诊。

合成例：某人报告运动后间歇不适。摘要只保留发生条件、持续情况、已有记录和影响；缺心率、血压或病史就标未知，不由AI补数或制定用药。若正在发生明显紧急危险，应先寻求即时医疗支持，不等待资料整理完成。

## 隐私与边界

准备摘要不要求把身份证、账号、完整病历发送到搜索引擎。药物记录用于沟通，不构成停药或改剂量授权。可核对[AHRQ就诊准备资料](https://www.ahrq.gov/questions/be-engaged/index.html)，但任何具体医疗判断仍需要当前证据和临床评估。
