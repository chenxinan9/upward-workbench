# 词汇卡与搭配迁移

适用：词汇记住释义却无法在表达中使用时。

## 选择值得保留的词

优先选择阻碍当前理解、经常遇见或能复用到真实任务的词组。一次不必把全文生词全部建卡。常用搭配比孤立中文对应更容易支持输出；多义词按本次语境记录，再逐渐补充。

词汇卡包含表达、所在原句或短出处、当前语境意思、搭配、易混项、自己的造句、反馈和回看状态。需要引用原文时保持最少必要长度；不要复制整篇材料。

## 合成卡示例

表达：make a decision。语境：讨论活动日期。当前意思：作出决定。自己的句子：“We need to make a decision about the venue.”后续练习改为过去或另一主体。卡片不必一开始收齐该词所有用法。

## 三种复习任务

从意思找表达，检查是否能回忆；在句子中选合适搭配，检查是否能辨别；用自己的情境造句，检查是否能应用。连续答对某一种题不代表另外两种也掌握。

记错时保留误用及原因，再给一个短重试任务。下一次回看时间可按近期表现调整，忘记不等于失败。口语用途需真实听音和发声练习；文字工具可以提示音标与需要注意的区别，不能在没有录音时判定实际发音。
