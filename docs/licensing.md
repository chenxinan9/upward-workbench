# 新版的个人使用和二次开发授权

自 `0.4.8-rc1` 候选版本起，本项目有权另行授权的新增原创内容与原创修改，采用[个人使用与商业授权许可](../LICENSE)。允许个人按许可和取得版本时的销售约定使用；二次开发、发布改版、转售、组织经营部署及向第三方提供经营性软件服务，需要事先取得单独书面授权。版本的获取方式、价格和配套服务由许可方另行确定，许可方保留销售自身版本和服务的权利。

该许可包含用途和再分发限制，属于“源码可见”的授权安排，不是 OSI 意义上的开源许可。GitHub 上能看到源代码，不等于获得任意修改和销售的授权。这些限制只在权利人有权另行授权的范围内适用，不靠改名覆盖他人的许可。

## 旧 MIT 版本继续有效

公开的 `v0.4.7-rc1` 对应提交为 `3b8a5207cf934d7069b6cdbf7c07aa98a1ed4b8b`。它及此前已经按 MIT 发布的相应内容仍按旧许可使用；旧版获得者仍可在 MIT 条件下修改和销售该部分。旧许可原文保留在 [legacy-MIT.txt](../LICENSES/legacy-MIT.txt)。

新版不能追回旧版的既有授权。将仓库设为私有、删除下载、增加一句“禁止商用”，也不能据此声称旧 MIT 版本的授权已收回。新版的原创增量可以另设条件，但不得把它包装成对旧代码销售的全面禁令。评估具体代码时，应结合固定版本、改动及来源判断，而不是只看根目录一个许可证名称。
