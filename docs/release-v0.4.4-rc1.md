# 睿顾台 v0.4.4-rc1

顾问团、成长工作台与本地知识库在同一处工作。本版沿用浅蓝书房和七个成长入口，原「向上工作台」更名为「睿顾台」，升级继续使用已有数据与知识库连接。

## 变化

- 顾问书房增加八类职责：事业经营、创作表达、学习求知、财务消费、健康精力、沟通关系、目标行动、思想判断。搜索和示例复用已有顾问资料，不自动发送。
- 顾问卡片优先显示原 Skill 说明中明确的用途；完整技能、配套参考和来源可继续打开阅读。卡片摘要与本轮实际读取、选用顾问分别呈现。
- 模型目录与对话使用同一个 Codex CLI。未指定专用路径时，优先采用本机已安装、版本可核实较新的官方 CLI；显式配置保持优先。主动刷新重新读取目录，不发模型请求、不修改全局模型配置。
- 修复窄聊天栏忙碌时模型状态与停止控件拥挤，以及小窗口隐藏导航后正文错列。
- 对话流式记录保留当前进度和生命周期历史，减少逐事件重复保存全量版本。附件解析不再占用会话锁；移除未发送附件可安全重试，并保护其他草稿和已发送引用。
- 修复明确保存新复盘并保护其他文件时被误拒，以及保存正文已带同名标题时重复添加标题。原文覆盖和写入范围仍需明确授权。

## 随包资料

51 份许可明确的顾问缩编 Skill、90 个配套参考文件、33 项登记去重方法；另有《高性价比人生指南》34 章、122 篇补充文档与 22 张来源导读。55 条来源目录与 51 份分发正文分别统计；四份许可受限或不明的原 Skill 不随包分发。原始署名与许可保持。

## 验证与使用边界

发布验收覆盖精确 ZIP 的自动回归、合成资料初始化、代表性顾问工具与真实模型调用、阶段复盘保存后读回、窄窗口操作、已有桌面入口安全升级，以及公开安装命令的下载和校验。各项具体回执由发布记录绑定最终提交和 ZIP；历史测试不自动证明新设备、其他账号或所有顾问问题均通过。

工作台显示实际工具进度、资料和顾问依据，以及模型提供的公开说明；不展示隐藏推理全文。模型可用性取决于该设备连接、账号与服务状态。语音设备授权和外部 MCP 工具仍需在使用设备逐项验证。

公开包不包含私人档案、真实目标、聊天、模型认证或个人创作宣传材料。程序采用 MIT，第三方资料按各自许可复用，见 [NOTICE](../NOTICE) 与 [资料说明](knowledge-library.md)。
