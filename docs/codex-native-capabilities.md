# Codex 本机助手使用说明

右侧对话保留成长顾问与知识库能力，并增加本机助手的原生执行工具。由本机 Codex app-server 建立会话，沿用本机已配置的账号和模型；工作台不是完整复制 Codex 桌面客户端。

## 日常操作

- 选择「我的资料与顾问」范围和「本机助手」，直接提出联网、查看文件、整理资料或写入工作目录的要求。原生联网和命令执行有真实工具状态及结果。
- 范围收窄到当前文档、顾问等时，自动使用「资料顾问」；工具范围变化会隔离模型线程，界面历史仍保留。
- 点击附件、拖入文件或粘贴图片，确认显示「已上传」再发送。一次最多 8 个，每个 20 MB。图片作为图像输入；文本和文档通过附件读取工具分页读取。
- 图片支持 PNG/JPEG/GIF/WebP，文档支持 PDF/DOCX/XLSX/PPTX，另支持常用文本。PDF 只提取前 60 页可选文字，扫描图像不自动 OCR。Office 提取正文和单元格，不执行宏、不重算公式，不将图表视为已读。受限或截断会显示说明。
- 桌面入口的麦克风按钮使用 macOS 语音识别；首次需要麦克风与语音识别授权。可用时优先本机识别，必要时使用 Apple 服务。浏览器是否支持听写取决于浏览器。
- 听写结果只进入可编辑草稿，不自动发送；停止、切换会话、关闭或刷新会取消当前录音。拒绝授权会显示错误，不假称成功。
- 「允许本次操作」只针对当次请求；可拒绝或停止。需要补充信息时在卡片提交。

## 能力和权限边界

本机助手可读取当前系统权限允许的本机文件，读取范围不只限于已登记知识库。普通命令不逐次审批；默认工作目录可写，目录外修改通过按请求审批。不要把附件接口的会话隔离误解成原生命令的文件读取隔离。

MCP 继承本机 Codex 的已配置服务，强制逐次提示；连接器须运行、完成授权并实际成功返回，才可视为可用。复杂授权或 URL 授权需要先在本机连接设置完成。桌面客户端专属浏览器、插件和连接器不会因 app-server 存在而自动全部可用。

显示的是工具调用、执行输出、顾问选用与公开分析摘要，不展示模型隐藏的完整内部推理。删除与外发等操作仍应严格遵循用户请求。

## 验证范围

原生联网、命令写入及回读、图片输入已用实际模型验收。协议、附件校验、审批取消、范围切换和旧功能有自动回归覆盖。真实录音仍需要用户首次系统授权和真人讲话验证；未逐一实测所有本机 MCP。机器路径、账号配置、聊天与验收日志均留在私有数据目录之外的私有工作记录中，不随公开代码发布。
