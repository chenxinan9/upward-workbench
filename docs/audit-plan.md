# 工作台独立审计计划

状态：审计计划，尚非通过证明。审计日期：2026-10-06。

本审计负责应用安全、数据真实性和关键状态完整性；不替代独立产品验收或公开文件包审计。审计以实际交付源码和可运行版本为准，发现问题交回实现者修复，再按相同触发条件复查。任何尚未执行的检查均标为未核验。

## 范围与取证边界

- 检查源码、运行配置、接口、前端关键行为和打包相关入口。
- 动态测试只连接使用隔离临时数据目录的审计实例，使用合成数据；不得创建、修改或清除真实用户目标、日志、会话、知识库或计划。
- 私有原始测试输出、请求响应和日志保存在仓库之外。公共报告仅保留净化后的步骤、结论、问题编号与版本摘要，不含机器绝对路径、账号、真实目标、健康与财务信息。
- 不向外部模型、站点或账户发送真实用户资料。涉及真实 Codex 服务的调用由实现者提供可核验回执；审计隔离测试不能冒充真实成功。
- 问题分为阻断、高、中、低风险，标明触发条件、影响、证据、修复要求和复查状态。阻断及高风险未关闭不得通过。

## 检查矩阵

| 编号 | 检查项 | 检查方法与通过条件 |
|---|---|---|
| SEC-01 | 本地监听边界 | 服务只监听回环地址；不以界面提示代替实际绑定检查。IPv4/IPv6 配置必须符合实现承诺。 |
| SEC-02 | Host 校验与 DNS 重绑定 | 对允许的本地 Host、错误 Host、恶意域名、伪造转发头发请求；只接受配置中的合法本机主机及端口，不能依赖转发头绕过。 |
| SEC-03 | Origin、CSRF 与会话凭据 | 跨站写请求、缺失或错误令牌、恶意 Origin、简单表单请求均不能修改数据或发起 Codex。允许的同源流程可成功；无宽泛跨域开放。令牌不经 URL、日志或公开静态文件泄漏。 |
| SEC-04 | 私有运行数据隔离 | 默认运行目录在项目之外；自定义路径受到校验；前端静态服务器与构建包不可读取私有目录、配置、索引或日志。 |
| SEC-05 | 文件访问范围 | 以路径穿越、绝对路径、编码路径、符号链接和非法文档 ID 测试读取接口。用户提供的任意路径不能变成通用文件读取器；仅能读取已授权的知识库条目。 |
| SEC-06 | 输入、输出与命令边界 | 输入校验、长度上限、HTML/Markdown 注入处理、参数化数据库操作、子进程参数和错误返回。用户文本不能形成 shell 命令；页面不能执行笔记内脚本。 |
| DATA-01 | 私有资料按需使用 | 默认不展示/发送整份个人画像。发送前能预览确切上下文，增删所选内容，并分清用户文本与检索资料。上下文预览与真正发送内容一致。 |
| DATA-02 | Codex 真实事件与状态 | 检查开始、运行、输出、成功、错误、取消和服务重启后的状态。只有真实完成事件才能标成功；模拟结果明确标注。断线不伪装完成，失败可读、取消可恢复，重复点击不误建任务。 |
| DATA-03 | 目标与行动闭环 | 验证目标、计划、行动和结果的关联及持久化。完成状态须能附带结果或证据；计划日期不是完成日期。禁止以模型建议自动充当用户执行事实。 |
| DATA-04 | 想法与知识库状态 | 保存笔记、申请入库、索引成功及检索回读应有不同状态；写入失败不显示成功。完成索引后通过唯一合成内容进行实际检索与回读，并验证删除/更新后的状态。 |
| DATA-05 | 金句与学习来源 | 原话应有可核对出处；方法转述明确标注。当天提醒稳定且来源可打开；不伪造顾问原话、阅读完成或掌握程度。 |
| DATA-06 | 统计口径 | 顾问、功能工作流、方法、文章、片段分别统计。不得把文件数冒充方法数或把来源目录冒充已授权公开的技能正文。 |
| OPS-01 | 数据持久化与故障 | 隔离实例重启后数据仍在；中断写入、非法 JSON、并发更新等不导致静默丢失。错误不会向界面泄露密钥或本机路径。 |
| OPS-02 | 移交与可复现 | 安装和启动文档与实际依赖一致；公开合成示例可运行；配置缺失时明确提示。应用审计结论固定到对应源码版本，后续改动需相应复查。 |

## 执行与退回流程

1. 读取最终需求、架构和数据目录约定，记录实际提供的功能及未实现项。
2. 静态审查实现；先报告会影响架构的高风险问题，避免在错误边界上继续验收。
3. 在独立临时目录运行服务并执行上述接口测试；记录实际执行项、通过项和未核验项。
4. 将发现交回实现者，审计员不直接修改功能源码。
5. 对修复版本重复原触发步骤，并检查是否引入相邻回归。
6. 产出公共净化审计报告和私有证据索引。任何未闭合问题不得用“整体通过”掩盖；明确哪些结论属于源码验证、隔离运行验证或真实集成验证。
