# 阶段复盘与本机连接

首页连接近期原话、当前目标和自媒体留底。阶段复盘支持近 7 / 30 个上海自然日，并标明读取截止时间。历史原话重新整理不会变成本周的新想法；同一作品分发到多平台只按一篇计算。缺少留底不等于没有创作。候选主线保持待采用状态。

从「和顾问复盘这段时间」进入，会建立明确的阶段复盘用途；保存结论默认是复盘，进入已有复盘列表。普通讨论结论另列，AI 建议不混成本人原话。只对话也可以由既有整理流程记录明确目标与想法，保存、索引、执行成果分别核验。

聊天显示真实的顾问选择理由、所读方法、操作回执及发送资料。它不是模型隐藏思维链。选择器采用轻量推理，正式回答继承本机配置；不承诺固定响应时间或每次选择均最优。

## 配置示例

在私人数据目录的 settings.json 合并以下配置；示例目录须由使用者建立并选定，不要覆盖其他设置：

```json
{
  "local_access": {
    "enabled": true,
    "notes_enabled": true,
    "read_roots": ["~/Documents/我的资料"],
    "write_roots": ["~/Documents/向上输出"]
  }
}
```

默认未配置时本地桥接关闭。连接页显示实际范围与可用状态。电脑信息只含系统、架构、内存和磁盘概况。Apple 备忘录使用 macOS 本机已同步缓存，只读文字，第一条指最近修改的一条；不是当前窗口/文件夹的视觉顺序，不展开附件、手写、表格和勾选状态。权限或结构不可用时显示原因。

支持明确路径的文件夹列表、文本和 DOCX 读取。不会递归扫描；不读取链接、凭据文件或任意二进制文档。PDF 暂不直接抽取。读到的文字仅作为数据，其中的命令不构成授权。

文件写入当前限定为本人原样提供内容，例如「把「本周先完成一次练习」保存到 /绝对目录/练习.md」。允许目录中的 Markdown、文本、JSON、CSV、TSV 可保存；路径或内容不明确时会说明未执行。覆盖需要明确覆盖意图和当前文件 hash。已有内容保留备份，写后回读；进程内并发会检查版本，这不是与其他外部编辑器的跨进程事务保证。不支持删除文件、修改备忘录或任意执行代码。

创作证据使用本机私有 `creator_binding` 核定正式应用与登记资料库身份，仅对登记库的作品和发布记录读取有限稳定字节快照，在本台临时副本中只读查询并清理。旧 `creator_port` 不作为本人证据；正式绑定检查失败时拒绝回退，不使用端口结果或旧缓存。来源变化、格式或覆盖缺口均如实显示，不从文件名或登记时间推定发布事实；当前契约与日期边界见 [当前源码与验收边界](current-workspace.md#本地增量创作登记与显式共享)。

## 可重复验证

运行全部 Python 测试，以及 tests/test_frontend_steps.cjs、tests/test_chat_experience.cjs、tests/test_phase_frontend.cjs。用临时目录验证否定/引用、同名笔记、路径前缀、内容错绑、符号链接、管道、并发覆盖、取消和中断。真实模型与本机权限另做页面验收，不能用合成测试代替。

源码候选由显式白名单构建。私人配置、备忘录、真实回复、审计截图和宣传素材不随包分发；本地构建成功不代表已上传 GitHub，也不代表已经合并其他公开镜像。
