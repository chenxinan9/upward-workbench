# 随包知识与顾问参考资料

这套项目同时提供可执行的顾问方法和可阅读的资料。下载 ZIP 或运行一键安装后即可阅读与搜索；连接自己的 Codex 后，模型通过知识工具按需读取，不必把全部文档塞进每次对话。

## 资料分为三层

| 内容 | 随包提供 | 出处与许可 |
| --- | --- | --- |
| 51 个顾问的方法入口与参考资料 | SKILL、方法研究、案例、练习与边界 | 各顾问 LICENSE 和 provenance.json，固定上游版本 |
| 《高性价比人生指南》 | 34 个 book 章节、122 篇 docs 补充和来源核实文档 | eternity4719/HowToLiveBetter 及其贡献者，CC BY 4.0 |
| 来源导读 | 22 份原创导读，包含合法阅读入口与适用问题 | 导读为本项目 MIT，链接目标各自保留权利 |

顾问案例为合成练习，不是用户经历、真实投资收益或经过临床验证的治疗方案。参考笔记由方法来源改编，保留固定来源和修改说明，不冒充人物原话或本人咨询。

指南锁定上游提交 `fcc93eb9a4bdc26e8a4e4c94bdaae0a89265927b`，来源 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter/tree/fcc93eb9a4bdc26e8a4e4c94bdaae0a89265927b)。原文作者已有核实记录，但本项目没有重新实证每条建议；使用医疗、法律、财务和政策内容作决定时要核对当前权威资料。补充文件数不等于独立方法数。

## 在工作台里用

1. 在顾问书房选择问题相关的顾问，先看方法入口，再展开参考资料。51 个入口都随程序提供，不必先安装到全局 Skill 目录。
2. 左侧“公开资料库”下有“高性价比人生指南”和“顾问来源导读”，可阅读或搜索具体主题。这两个集合只读，避免把公共原文和个人笔记混在一起。
3. 右侧可以说：“从随包人生指南查找这个问题的相关章节，再选一位顾问，给出依据、适用条件和下一步。”回答应区分已读正文和仅找到的链接。
4. 想保留应用结果时，说：“把这次结论整理到我的笔记，保留资料出处。”写入你自己的笔记空间，不修改公共原文；目标需明确采纳后才成为进行中的目标。

“仅顾问”范围在当前版本显示为“顾问与公开资料”，允许读取上述公共集合，不读取个人记录。按当前文档讨论时，顾问及公共参考仍可用于方法支持。查看资料不需要模型账号；AI 对话需要用户自行完成本机连接。

## 原著和外部资料怎样处理

纳瓦尔原著、巴菲特股东信、部分历史经典、健康机构材料和天涯帖子并非全部随包提供全文。导读有来源、用途与阅读边界；巴菲特有伯克希尔官方历年股东信目录，不限于两封。公开能阅读不代表可以任意镜像整部作品，许可未明确的原 Skill 和原著正文不会因为脱敏就改标开源。

你可把自己合法取得的资料放入单独 Markdown/TXT 文件夹，再按 [接入说明](getting-started.md) 登记。私人接入不会修改本仓库，也不要求把自己的资料公开。外部网页只有真正读取后才算正文依据。

## 更新与复用

顾问资源在各自 `provenance.json` 登记；公共知识在 `knowledge-bundle/manifest.json` 登记路径、字节数和 SHA-256。构建、顾问安装和桌面复制依据明细校验，拒绝未登记文件、内容被篡改、越界路径和符号链接。增加资料必须补全来源、许可、改动和哈希，再跑检查；单把文件放进目录不算纳入发行版。

升级不会把公共库路径写死到私人配置；工作台从当前程序目录发现这些集合。现有个人笔记、模型配置与对话仍保存在使用者自己的数据目录。公共库升级与备份私人数据是不同操作。
