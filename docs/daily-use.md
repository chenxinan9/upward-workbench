# 日常使用

向上是日常主界面，Obsidian承载同一份Markdown。左侧依次进入我的今天、人生全景、目标与计划、近期想法、阶段复盘、顾问书房、我的知识库；右侧Codex持续对话。今天看当日行动，全景看长期生活方向，目标看阶段计划，复盘看近7/30天真实记录，不是重复页面。

## 读一份内容，接着讨论

打开项目、近期笔记或顾问 Skill。当前文档会出现在输入区的资料提示中；可选择一段文字再提问，也可移除当前文档，只讨论问题。Codex 按需检索、读取相关资料，并显示实际用过的顾问和来源。

例如：“这段方法怎样用于我现在的项目？”“请先查我最近的记录，再帮我识别阶段瓶颈。”来源没有覆盖到时应补读或承认未知，而不是假装已经理解全部知识库。

人物顾问是方法视角，随包内容是缩编 Skill。多位顾问提供不同判断依据，不代表拥有名人本人或其全部著作。简单问题不必强行召集所有顾问。

## 用对话整理想法和计划

新想法可以先直接说出来。想把结论留下时，直接说“记下这个想法”“保存这次阶段复盘”或“把这个计划保存为候选目标”，不必先手工新建文档。确认计划后说“我采用刚才这个目标”；后续可说“更新这项目标的日期为……”或“我完成了，实际结果是……”。当前明确采纳、完成及证据分别核对，不把保存计划当自动承诺。如果仍在取舍，就标明“这是候选想法，不是已经决定的目标”。

写回应显示文档与保存回执，左侧正文更新后可以继续编辑；需要恢复时使用撤销。看到了模型回复不等于文件已经保存，必须看写入结果。只读集合和 TXT 原件不能通过聊天绕过限制。

目标、计划和阶段复盘保存在普通 Markdown 中，与主界面各视图相连。近期想法纳入本人新旧会话原话，不把助手建议当本人事实；阶段复盘区分发生日期和整理日期、作品留底与实际平台核验。先记真实变化，再请 Codex整理；不需要为了填满页面虚构进度或个人情况。

## 学习顾问内容

从顾问团打开方法，阅读其中的适用条件和边界。让 Codex 解释难点、比较两个方法，或把一个方法转成具体实验。实际使用后，把结果写回自己的项目，再链接到这份顾问资料。

比“我读完了几个顾问”更有价值的是留下一条清楚记录：当时的问题、用了什么方法、做了什么、观察到什么，以及是否继续。

## 与 Obsidian 共用同一文件

在 Obsidian 或其他编辑器保存后，向上会检查磁盘版本并重新读取。正在编辑的草稿不会因为外部变化而无声丢失；出现冲突时保留草稿、重读最新文件，再决定怎样合并。

编辑草稿和未发送的聊天输入会按数据空间、文档或会话保存在当前浏览器，刷新后可恢复；若磁盘版本已经变化，会提示草稿冲突。浏览器草稿不属于已保存的 Markdown，也不在文件或数据库备份中，请先保存再备份。

向上保存的就是 Markdown 原文，不需要再手动“并入知识库”。搜索是渐进扫描，反链是已知链接快照；扫描未完成时不能把当前没有命中当作全库不存在。

## 继续同一段对话

从右侧历史会话继续，Codex 会复用这段工作台会话。切换文档不会授权修改上一次的文档；写权限和当前文档按本轮核对。新话题可以新建会话，避免不相关的任务混在一起。

等待区显示工具动作、公开进度和分析摘要。模型可用状态与知识库可读状态是两件事：没有模型时仍可阅读、编辑与搜索。停止后检查已发生的文件操作回执，必要时撤销。

## 留好备份

定期停止服务后备份。默认数据目录备份包含工作台记录及其中的笔记；外部 Obsidian Vault 需要独立备份，或显式用 `--vault-root 集合ID` 纳入本次备份。恢复时使用新目录，核对集合重映射，避免写回原件。

备份、安装回滚副本和会话都可能包含私人内容。公共分享只选择已经脱敏且有分发权的材料，不能把整个私人数据目录打包上传。

## 本轮用途、范围与本机协作

右侧可选用途、近7/30天以及个人成长/当前文档/仅顾问范围，也可在顾问书房指定顾问。仅顾问不附个人文档或本机工具，收窄范围时隔离模型旧线程。显示实际选用理由、已读方法和工具动态，不显示隐藏完整思维链。

在本机已经配置的范围内可说“查看我的电脑信息”“列出最近备忘录”“读取这个文件”。备忘录使用本机同步缓存，只读文字；指定文件写入需要本轮明确路径与内容。模型与连接设置显示本机实际状态。

工作台里的Codex适合日常成长、顾问学习与记录；桌面Codex主对话适合开发、维护和跨项目工作，两边不自动共享全部聊天。
