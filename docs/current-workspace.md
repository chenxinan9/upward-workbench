- 未指定专用 CLI 时，在 PATH 与标准 macOS 官方桌面应用内的 Codex CLI 中使用可核实版本较新的一个；目录和实际对话沿用同一个执行文件。显式指定的 CLI 保持优先，刷新模型目录不调用模型，也不修改全局配置。
- 顾问卡片优先展示原技能说明中已有的用途文字；窄聊天栏的模型、停止与发送控件保持可读。卡片摘要不代替完整 Skill 或实际读取回执。

## 本地两项增量：对话更新与资料日期

个人全景与今日重点仍来自唯一登记的私有 `growth_plan` JSON。明确说“把长期方向更新为……”或“把今日重点设为……”时，助手先用 `read_growth_plan` 读回当前可编辑部分、版本和整份文件 SHA，再用 `update_growth_plan` 传需要修改的字段。该路径在资料顾问与本机助手中都使用相同受控工具，仅限本轮 `personal` 范围；不需要再填表或对明确指令重复确认。讨论、假设、引用、转述、否定或不明确的对象不授权写入。

全景支持长期方向、标题和已有维度、路线的部分修订。维度/路线必须点名唯一的已有标题、标识或序号；不批量替换数组，不改用户未指定的维度。今日重点单独记录上海适用日期，昨日重点仍作为历史可见，不算今天已确认。新方向原话关联本轮可回读陈述，原来源及日期留在历史，不冒充旧资料原文。

写入采用原有文件安全辅助、SHA 冲突检查、私有 JSON 备份、写入日记、原子替换和实际读回。写前验证候选仍能按相同规则读出。只有 verified 回执才显示成功；正在回答时收到新回执便刷新成长视图，不切换当前导航、不清空未发送草稿。JSON 回执跳转对应成长页；撤销按当前 SHA 核对，外部已有新修改时拒绝覆盖。恢复材料只在私有数据目录。

相关成长页面的小型折叠区显示方案形成日/修订日，以及每个登记来源的原始日期、登记/核对日期、本人事实确认日期、登记版本、当前文件版本和文件修改时间。缺失日期明确标未登记。仅检查登记源，不全盘扫描；外链本次不联网，配置型外部台账按实际登记目标核对。版本未变只表示同版本，不证明历史情况现在仍有效；mtime 不是本人事实日期。当前检查时间不会写成来源上次核对时间，编辑方案也不会替用户更新来源确认日。

无私有方案的公共安装保守显示未配置，不自动生成个人方案或扩大目录权限。本地两项说明不表示公开下载包已升级，真实模型、界面和安装验收另留私有回执。


## 本地增量：创作登记与显式共享

创作证据只认本机私有设置中 `creator_binding` 核定的正式应用与资料库。旧格式固定 `release_path`、`release_sha256`、`workspace_id`、`registration_sha256`，继续严格校验发行文件字节；公开包不包含实际路径、身份锚或个人记录。先校验发行信息、登记文件、目录与库的身份和版本，再只读登记库的 `projects` 与 `publication_records`。旧 `creator_port` 不能代表当前本人资料；正式绑定失败不会回退到旧端口。

核对过同一批准资料库后，可在本台私有绑定中显式固定 `registration_path`。此模式将数据授权绑定到该登记文件的原 SHA、workspace ID、批准目录及数据库身份，而不因应用发行文件单纯升级版本就断连。发行文件仍须是本机所有、非符号链接、有大小上限且读取期间稳定的 JSON；app ID、生产用途、登记路径和登记 SHA 必须匹配批准值。登记文件、目录、数据库 inode、内部 metadata、schema 和读取范围仍逐次验证。新字段无效直接失败，不能静默降级；不得跟随发行信息选择新登记路径或自动批准新数据源。`release_sha256` 保留为核对时的版本记录，不再是此模式的数据授权锚。

源库由普通只读文件句柄读取稳定的有限字节快照（最高 64 MB），SQLite 只查询本台临时目录里的副本并立即清理，避免只读 SQLite 在源目录产生 WAL 协调文件。当前仅支持 DELETE 日志模式且源目录无协调文件；WAL、读取期间变化、身份变化、过量或格式缺口都明确提示，不把未核对数量当作零。

作品创建、作品更新、发布发生日、本人报告日期、发布登记时间与本次读取时刻分别保留。登记时间不补作发布日期；缺发生日的已发布记录不计入某天日更。仅按本地登记库覆盖范围做阶段复盘，不称为实时平台核验，也不以没有近期记录推断没有创作。

在知识库左侧切换“已共享给睿顾台”，空搜索也会显示目录状态和查看入口。目录可用与正文授权可用分别核验；只有目录 active 不代表已经读到正文。若来源范围或隐私规则变化，界面提示回知识工作台重新分享，并保留当前问题与片段选择；睿顾台不修改其他工作台来绕过该限制。查看、选择、发送前预览确认、发送时与工具读取时再核验、撤回失效和只保存来源元数据的边界继续生效。上游故障仅映射为固定安全提示，不展示上游原始错误正文、连接秘密或文件路径。

## 本地增量：导航、会话与成果反馈

中间内容区上方提供当前页面内部区块的横向目录，点击定位同页内容，不重复左侧主栏目。目录随当前页面实际内容变化，知识文档使用真实标题；编辑或没有可定位区块时隐藏，不保留空白占位。左侧顺序为我的今天、近期规划、人生全景、阶段复盘、顾问书房、我的知识库。近期想法从独立主入口移到近期规划内部，旧路由保持兼容，资料没有删除。浅蓝三栏与右侧对话保持原结构，原有草稿保护继续生效。

会话标题旁的更多菜单支持重命名、删除确认和已删除会话恢复。删除是本台可恢复归档，不删除消息、附件、成果或模型线程。进行中的会话先停止本轮，再删除。另一个窗口删除或恢复会话时，当前窗口以服务端状态为准，保留未发送草稿，不在失效会话中继续发送。

Codex 后台线程使用“睿顾台 · 会话名称”，同一资料与执行范围内沿用原线程。每轮结束后自动将确认属于本台的引擎线程从 Codex 最近列表归档收起；工作台会话、回复、附件和成果继续保留，下次按原线程 ID 恢复。资料范围收窄或服务变化仍保留必要的上下文边界，不强行混用私人历史。归档或命名失败单独记录，不把有效答复改成失败，也不自动重发。执行中可能短暂显示后台线程；这不是新增了一份工作台会话。这些引擎线程由睿顾台管理，不支持同时在桌面与睿顾台并行继续同一个引擎线程；连接内的活动状态检查不能充当跨客户端全局锁。

回复中的成果卡只使用实际工具回执：保存并回读成功后才显示成功、打开和可用的撤销；同一记录以最新状态为准，不能让旧成功掩盖新失败。成长方案显示后端真实版本；普通文档显示内容校验值，不编造版本。保存及撤销成功都会刷新对应成长内容，并保留当前导航和输入草稿。模型口头说“已保存”不能替代回执。

本台通过官方 Codex app-server 使用本机登录，具有同源引擎，但不是 Codex 桌面应用工具的完整透传。本机助手开放实际可用的联网、命令、图片查看和已配置连接；资料顾问限定受控知识工具。电脑控制、桌面插件、页面编辑器、语音和结果预览分别依赖本台适配、系统授权与实际工具，不因选择同一个模型自动全部存在。当前成果卡用于已核实的知识文档、成长记录和个人方案；不是任意生成文件的通用桌面预览器。

每轮将当前范围内的顾问目录提供给模型。成长、学习、经营、复盘等建议问题要求先完整读取适用 Skill 和必要参考，再记录实际采用理由；纯寒暄或没有适用方法时不虚构顾问调用。历史依据与本轮读取分别显示，不能拿以前看过的方法冒充本轮已采用。

明确说“记下这个想法”“保存本次复盘”“采用这个目标”“把今日重点改成……”时，可通过受控工具更新并回读；普通讨论不会自动变成已采纳目标。每次对话保留在会话中，知识库记录与已确认计划按各自状态保存。

接口失败显示实际阶段和安全错误码，不将所有失败称为内容拒绝。仅在恢复同一条模型线程时收到精确的“已归档”错误，且尚未开始本轮，才执行一次固定的取消归档操作并恢复原线程；模型和历史保持，本轮最多发送一次。认证、额度、网络或其他错误不通过换模型、重复生成或执行错误文本中的命令来掩盖。

## 本地增量：近期规划、成果展开与新顾问

近期规划整合目标计划、行动拆分、近期想法和未采纳候选。我的今天不再展示近期想法；只提醒明确日期的未完成行动，逾期和未排期另列。通过对话拆分的步骤保留日期、完成标准和结果状态，未明确日期不自动安排今天；建议与采纳仍分开。
