## 复现检查

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.cjs
python3 examples/init_demo.py --data-dir /tmp/upward-demo-new
python3 tools/setup_knowledge.py --data-dir /tmp/upward-demo-new
python3 app.py --data-dir /tmp/upward-demo-new --port 60129
```
