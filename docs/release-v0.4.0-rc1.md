# v0.4.0-rc1：本机助手与更宽裕的对话区

这次更新保留顾问团、成长页面和 Obsidian 共用知识库，把 Codex 的本机能力与日常对话体验补齐。

## 可以做什么

- 在“本机助手”中联网查资料、运行命令、读取本机文件、写入工作目录并核对结果；越界操作按请求审批。实际工具进度、顾问选择与结果可查看。
- 通过附件按钮、拖放或粘贴加入图片和文档；macOS 桌面及支持的浏览器可听写到草稿。
- 把用途、范围与连接设置收进“对话设置”；回复正文优先显示，详细证据按需展开。读历史时不再被新进度强行拉回底部。
- 输入框默认高度由 42 调整为 56 像素，长草稿按内容伸展并封顶；附件、语音、模型和发送保持一行。审批以紧凑入口提醒，完整内容在独立面板核对。

## 资料与安装

51 份可分发顾问 Skill、90 份配套参考、人生指南 34 章与 122 篇补充文档、22 份来源导读继续随包提供，原许可与来源保留。安装命令见首页；脚本校验固定版本的 ZIP 哈希，不覆盖已有数据目录。已有桌面用户按[升级说明](../desktop/README.md)保留自己的数据目录升级。

## 权限与验收范围

本机助手可读取系统权限允许的文件，不只限于登记的知识库；默认工作目录可写，普通命令不一定逐次审批。当前文档或顾问公开资料范围会使用受限资料顾问，并隔离旧模型上下文。MCP 需本机配置与授权，不等于继承全部 Codex 桌面插件。

原生联网、命令写入与读回、图片输入已有实际模型验收；自动回归覆盖附件解析、跨会话隔离、审批撤回、草稿和聊天滚动等。真人录音及每一种 MCP 连接器尚未逐一验收，因此仍为预发布版。展示公开工具动态和分析摘要，不展示隐藏推理全文。

公开材料只有程序、通用方法、许可明确的顾问与知识、合成示例；私人数据、真实聊天、账号配置、验收日志和宣传创作材料不随包发布。当前包的检查不能证明历史托管缓存已经消失。
