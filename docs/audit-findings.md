## 安全与状态检查结果

- 实际服务只监听 `127.0.0.1`。
- 非法 Host、非法 Origin、缺失会话 token 均返回 403；正确 token 的合法同源写请求返回 200。
- 数据默认位于项目外；静态文件采用固定映射，没有接受任意文件路径的读取接口。知识库读取按受控索引 ID 获取片段。
- 重复 request ID 返回同一笔记；过期修订拒绝覆盖。queued/cancelling 任务在重启后显示中断，不伪装完成。
- 预览与发送数据一致；取消、错误和工具事件不会被当成正常成功。目标完成需要结果说明，行动勾选明确为本人自报。
- 每日提醒均提供表达类型与来源字段，转述/意译与原文有区别。本轮审计核对字段与展示逻辑，来源全文核查由调研/验收承担，不重复声称逐条完成独立学术核源。
