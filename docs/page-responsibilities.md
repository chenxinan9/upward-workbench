# 成长工作台的三个时间层级

## 人生全景

回答“我想把人生过成什么样”。从私有配置 `life_panorama` 读取本人愿望、价值、生活维度、长期路线、历史变化和出处。每条内容标明本人陈述、历史资料或整理建议。无资料时不填入虚构用户画像。不能用任务完成比例表示人生进度，也不能把旧AI预测当作本人承诺。

## 目标与计划

回答“这一阶段推进什么，怎样判断进展”。保留已采用目标、行动安排、完成证据与复盘；候选方案和已采用目标分别显示。用于管理周期、日期和结果，不重复全景的愿望卡。

## 我的今天

回答“今天具体推进什么”。当前日程只显示到期行动，逾期、未来和未排期各自说明；未采用的建议不能伪装成当天任务。首页保留每日提醒、当前学习和随手记，不再铺开全部人生领域。

导航顺序：我的今天 → 人生全景 → 目标与计划 → 想法与复盘 → 与Codex协作 → 顾问书房 → 我的知识库。

## 复用与验证

通用代码只渲染配置，个人原话、原件路径与健康家庭信息留在私有数据区。修改后检查：三页内容职责不同；全景出处可回读；阶段计划可调整；未来行动不会显示为今日；无个人资料的公共界面可使用；窄屏导航及正文无横向溢出。

本次源代码修订不改变之前已封存的发行包。需要分发时重新打包并审计，不能拿旧包代表新界面。
