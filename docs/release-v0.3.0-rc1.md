# v0.3.0-rc1：顾问团、成长记录与知识空间融合

本版将今天、人生全景、目标、近期想法、阶段复盘和顾问书房接回共享 Markdown 知识空间，右侧 Codex 对话随页面保留。向上仍是日常主界面，Obsidian 可编辑同一批本地文件。

## 本版变化

- 长期方向、阶段目标与今日行动分别呈现。未采纳的方案和未排期行动不会自动成为今日任务。
- 最近 7 天或 30 天复盘结合有日期的目标、想法、学习实践及活动记录；历史资料重新导入不按导入日冒充近期事件。
- 对话可直接保存想法、候选目标和阶段复盘；明确采纳或更新后回读文件，刷新对应视图。
- Codex 采用持久会话、用途预设、顾问选择与后端执行的资料范围。实际读取、顾问选用理由、工具进度和保存回执分别显示。
- 共享 Markdown 编辑保留草稿与版本校验；电脑信息、备忘录和文件操作经过单独配置的本机工具。
- 保留浅蓝书房界面、顾问书房在知识库上方的顺序和 macOS 桌面入口。

## 公开包与许可

公开来源目录 55 条，随包 51 份顾问缩编 Skill，登记方法 33 项；这三项不能合并成“55 位真人顾问”。4 条来源因许可条件未分发正文。项目原创代码使用 MIT，第三方缩编遵循各自保留的许可。

包内仅含程序、可分发顾问、通用流程和合成示例。个人档案、真实目标、健康财务、私人对话、模型回执及宣传创作资料均不分发。安装器创建独立演示，不自动登录或调用 AI。

## 验证范围

融合候选的先前本地回归为 **335 项 Python 测试和 44 项前端测试通过**；这是该候选的验证记录，不是所有顾问效果的测评。

先前另以合成材料完成两轮真实 Codex 验收：读取纳瓦尔方法并保存候选目标，下一轮明确采纳后更新目标并出现当天行动。该流程有文件写入、回读和持久线程记录；私人运行回执不随包分发。此证据不代表 51 份随包 Skill 已逐一进行模型质量评测，也不代表所有备忘录或本机文件操作都经过真实模型遍历。

本次发布前的新增检查结果见 GitHub Release 说明与对应提交的 Actions。安装成功、测试通过与使用者最终体验验收分别记录，不据此承诺人生结果或模型回答质量。
