# v0.4.7-rc1

这一版补充顾问方法，并合并此前本地版的个人方案与共享知识改进。

## 顾问能力

- 新增选项比较：明确硬约束与替代方案，分开证据和偏好，给出有条件的取舍。
- 新增事前风险推演：从可能失败的情景倒查风险、早期信号、缓解措施与停止条件。
- 新增阶段反思：在指定期间内比较预期、实际行动和反馈，整理反复出现的想法及未完成事项，不把缺记录算成没有行动。
- 增强一人公司方向验证、获客与交付：访谈过去的真实行为，以可核查的承诺和交付验证假设，并考虑价格、产能和服务成本。

随包有54份顾问方法入口、35项登记方法。事前风险推演归入已有逆向思考方法，不因新增顾问入口重复计算。人物方法视角和功能顾问分别保留，方法数不等于人物数；配套参考文件数量以 `tools/metrics.py` 输出为准。新增入口及完整来源见[顾问清单](advisors.md)。

新增和改编内容保留固定来源、许可及修改说明；未复制访谈、通讯或著作全文。不会自动连接营销账号、读取全部历史或保存逐字稿。

## 对话与书房

主聊天框使用 Enter 发送、Shift+Enter 换行；保留 Cmd/Ctrl+Enter，中文组合输入与长按回车有防误发保护。发送继续经过原有资料范围、附件和共享预览检查。

默认书房背景的黑板右下角加入两行逐字对齐的粉笔字“好好学习”“天天向上”。浅蓝界面保持，使用者已配置的私人背景优先。

## 之前本地增量

明确要求更新长期方向或今日重点时，使用读取、版本冲突检查、原子写入和回读回执更新个人方案。对话中的想法、建议与已采纳目标保持区分，资料日期与文件版本可以回看。

创作记录只通过明确配置的本机来源读取，身份或版本检查失败时不回退旧端口。知识共享只读取原知识工作台明确分享的片段；发送前预览并确认，来源变化会拒用并保留问题。升级不会替使用者新建分享或扩大资料权限。

## 验证边界

自动化测试使用合成数据和模型替身，核对方法发现、完整读取后选用、资料范围、保存、附件、安装与资源校验。它们不证明任何建议必然有效，也不证明每台电脑的外部模型、麦克风或 MCP 已可用。

私人档案、实际会话、电脑配置、真实目标、模型回执、审计日志与宣传创作资料均不随公开包分发。已有自定义顾问目录继续由使用者维护；升级程序不会静默改写全局 Skill。
