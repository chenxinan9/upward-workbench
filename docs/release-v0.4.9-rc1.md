# 睿顾台 v0.4.9-rc1

本版修复发送前的模型目录超时，并把 Codex 后台会话交回睿顾台管理。浅蓝书房、顾问与公共知识资料、现有会话和个人使用与商业授权许可保持。

## 发送与草稿

- 模型目录的初始化、账户与列表读取总时限由 10 秒调整为 30 秒；前端对应等待 35 秒。
- 成功目录仍缓存 30 秒，从读取完成起计时；失败仅缓存 2 秒。重叠刷新共用一次在途读取。
- 账户、配置、服务与实际模型核对继续生效，不因目录读取失败自动换模型。
- 确定的目录拒绝显示本条未发送，保留输入、附件与选择；网络中断等不确定情况要求先核对会话，不自动重发。

## Codex 后台会话

- 后台线程使用“睿顾台 · 会话名称”，不再用内部 JSON 作为显示标题。
- 同一会话在相同资料与执行范围内恢复原线程；每轮结束后归档收起本台确认所属的后台线程。工作台历史、附件和成果保留。
- 资料范围缩小或服务变化仍保留上下文边界；不会为减少条目而混入之前较宽范围的私人资料。
- 命名、归档失败单独留回执，不把有效回答改成失败，不重新生成。DeepSeek 沿用原有独立运行配置。

后台执行时可能短暂显示清楚命名的线程。该引擎线程由睿顾台管理，不支持同时从 Codex 桌面和睿顾台并行继续同一个线程；单连接状态不是跨客户端全局锁。

## 验证范围

两项修复已通过 305 项定向回归及独立审查，覆盖慢启动、缓存恢复、并发刷新、草稿与附件、线程命名、续聊、取消、型号不符和整理失败。当前 Codex CLI 的实际隔离元数据验收验证了命名、跨进程读取恢复和归档，未发起模型轮次。

发布包还由独立角色按精确文件清单、安装保护和合成资料进行检查，云端结果见本版本对应的 Actions。上述检查不代表所有顾问效果、模型服务或设备均已验收，也不保证网络故障不会发生。

公开内容不含作者的 Codex 认证、DeepSeek 密钥、个人档案、真实目标、会话、运行资料或私有审计日志。安装者使用自己的本机登录或 API 凭据，费用由其所选账户承担。既有 GitHub 历史缓存的处理与本版发布分开，不将发布成功称为历史隐私已清零。
