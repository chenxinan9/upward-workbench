# 睿顾台 0.4.8-rc1

这版可以用自己的 Codex 登录，或接入自己的 DeepSeek API。在同一聊天切换服务，可以继续前面的问答；顾问、知识、受控读写与成果沿用同一工作台。浅蓝书房布局保留。

## 本版内容

- DeepSeek V4.1 Flash（接口 `deepseek-flash`）及 V4 Pro。DeepSeek 路线仍需可运行 app-server 的 Codex CLI 作为工具引擎，但不需要 ChatGPT 登录或 Pro 订阅。API 费用由使用者自己的 DeepSeek 账户承担。
- macOS 密钥进入系统钥匙串；模型子进程只取得本轮本机转发令牌。官方 HTTPS 上游固定，不跟随跳转，不将密钥或作者认证打包。Linux 使用本机启动环境，专用凭据变量不传给工具子进程。
- 同一聊天切换模型保留历史。后台承接同资料范围的有界问答，不搬隐藏推理、原生工具日志和失效共享片段；图片能力按模型检查，共享预览标明实际服务。
- 此前维护增量一并纳入：近期规划整合目标、行动拆分与想法；明确日期的行动在今天提醒；会话重命名/删除恢复；最右侧按需查看回复、写回和受控生成文件。
- 56份随包顾问、95份参考、37项去重登记方法，另有34章指南、122篇补充及22份导读。60条来源目录不等于60份分发正文。

## 接入

从右侧对话设置进入“模型与连接”，保存本人的DeepSeek API密钥，在模型选择器切换服务。保存、打开和刷新不发试答；明确点击试答或发送问题才使用模型。DeepSeek网页/App账号不能直接当API密钥。[完整步骤](deepseek-and-codex.md)。

公开包不包含作者的Codex登录、API密钥、私人资料或真实聊天。Codex使用客户本机自己的登录；DeepSeek使用客户自己的开放平台账户。当前AI助理使用本台实际提供的工具，不能因模型相同就宣传为完整复制桌面应用。
