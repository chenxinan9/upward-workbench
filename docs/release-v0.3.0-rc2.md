# v0.3.0-rc2 · 随包顾问资料与公共知识库

本版补齐“有方法入口，却缺配套阅读材料”的使用断层。保留浅蓝书房、七个成长视图、右侧 Codex 与本地 Markdown 工作方式。

## 变化

- 51 个顾问入口增加带来源的方法详解、合成案例、练习与边界，可按入口继续阅读。
- 随包分发《高性价比人生指南》34 章和 122 篇补充/核实文档，保留 CC BY 4.0 署名、固定版本及改动记录。
- 22 份来源导读，说明哪些是正文、哪些是合法阅读入口；公共材料不当成用户个人经历。
- 新安装自动出现两个只读公共集合；顾问与公开资料范围支持检索、读取这些内容，同时隔离私人记录。
- 独立顾问安装器复制已登记的 references/examples；ZIP 构建与桌面安装保留全部核验资源。
- 逐文件大小与 SHA-256 校验、未登记文件拒绝、路径穿越与符号链接防护，并拒绝覆盖已有同名技能。

## 复用范围

程序与原创流程按 MIT；第三方内容依各自许可。四份许可不明确或受限制的原 Skill 仍只保留来源。没有打包原作者的私人资料、对话、目标、模型认证、电脑路径或宣传创作材料。完整材料范围见 [知识库说明](knowledge-library.md)。

## 验证边界

验收重点是新安装后的实际文件复制、工作台检索与读取、公共集合写入拒绝、顾问作用范围，以及原有工作流回归。文件与工具链验收不等于所有模型、所有问题的咨询质量已验证；公开包不提供用户账号或模型额度。阶段性数据使用合成示例。
